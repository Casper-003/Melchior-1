# 滤波放大电路供电修改

开始日期：2026-09-17。

本次工作将原滤波放大电路由±5V供电改为+12V和0V供电，增加约6V偏置，并进行扫频和放大测试。目前是单独模块的仿真备份，尚未完成整机联调或实物验证。
