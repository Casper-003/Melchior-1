## 后续整理方式

每个新实验建立一个 `日期_实验名称` 文件夹，例如 `2026-09-17_滤波放大电路供电修改`。同一个实验后续的修改继续放在原实验文件夹中，不需要每天重建一个实验目录。

实验内部按需要使用以下分类：

- `Docs/`：进度、报告和操作说明。
- `Files/`：Multisim等软件的原始工程文件。
- `Pics/`：电路截图和测试图片。
- `Data/`：原始数据与分析结果，有数据时再建立。
- `Code/`：实验程序和分析脚本，有代码时再建立。

报告放在 `Docs/` 中时，图片使用 `../Pics/图片名称.png` 这样的相对路径。下载或发给他人时保留目录结构，图片仍能正常显示。

GitHub可以直接显示Markdown报告和图片。Multisim工程文件需要下载后用Multisim打开；HTML报告需要下载后在浏览器中打开。文件更新后继续提交到同一目录，Git会记录每次修改。
